To activate the autoplay video loop in the homepage hero:

1. Export a short clip from real service footage (10-20 seconds works well — worship, a wide shot of the room, kids ministry, etc.)
2. Format: MP4 (H.264), no audio needed since it plays muted, ideally under ~15MB so it loads fast
3. Name the file "hero-loop.mp4" and drop it in this folder (assets/video/)

That's it — index.html already points to assets/video/hero-loop.mp4 and will start playing it automatically.
If no file is present, the homepage hero shows a placeholder photo-collage grid instead, so the site still looks intentional either way.
